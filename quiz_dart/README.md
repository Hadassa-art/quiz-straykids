# Quiz Stray Kids

**Aluna:Hadassa Oliveira Moraes
**Trilha:** (desenvolvimento mobile)

## Sobre o quiz
Quiz de terminal feito em Dart sobre o grupo Stray Kids. O jogador
informa o nome, responde 5 perguntas de múltipla escolha (A, B, C ou D)
e recebe a pontuação final com uma mensagem de acordo com o desempenho.

## Exemplo de pergunta
Quem é o líder do Stray Kids?
A) Felix
B) Changbin
C) Bang Chan
D) Lee Know

## Como executar
Dentro da pasta do projeto, rode:

dart run
